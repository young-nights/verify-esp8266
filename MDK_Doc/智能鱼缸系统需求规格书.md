## 1 项目概述

### 1.1 项目名称

基于 STM32 的智能鱼缸监控系统

### 1.2 项目目标

设计并实现一款低成本、低功耗、易扩展的智能鱼缸监控系统。系统通过传感器实时采集水质参数（温度、水位、PH、空气质量），自动控制加热、加水、排水、增氧等执行机构，并通过 OLED 本地显示与 WiFi 远程上报实现双通道人机交互。

### 1.3 目标用户

- 观赏鱼爱好者（家庭用户）
- 水产养殖初学者
- 嵌入式课程设计 / 毕业设计参考

### 1.4 核心功能一览

| 编号 | 功能 | 优先级 | 说明 |
|------|------|--------|------|
| F01 | 水温采集与显示 | P0 | DS18B20 (PB13)，精度 ±0.5 °C |
| F02 | 温度自动控制 | P0 | 滞环控制：低于下限开加热，高于上限关 |
| F03 | 水位监测 | P0 | ADC 采集 (PA1)，0~100% 百分比 |
| F04 | 水位自动控制 | P1 | 低于 min 开加水，高于 max 开排水 |
| F05 | 空气质量监测 | P1 | MQ-135 ADC 采集 (PA4) |
| F06 | 空气质量自动控制 | P1 | 超标自动开增氧 (PA15) |
| F07 | PH 值监测 | P1 | PH 传感器 ADC 采集 (PA0)，0.0~14.0 |
| F08 | OLED 本地显示 | P0 | SSD1306 128×64，3 主页面 × 子页面 |
| F09 | 5 键参数设置 | P1 | KEY1~KEY5 独立按键导航 |
| F10 | 声光报警 | P0 | 蜂鸣器 + LED (PB9) |
| F11 | 自动喂食 | P2 | 舵机 SG90 (PA6 TIM3_CH1) |
| F12 | WiFi 远程上报 | P2 | ESP-01S USART2 (PA2/PA3) |
| F13 | 手动控制继电器 | P1 | 主页面 3 手动模式控制 4 路继电器 |

### 2.3 定时器调度架构

系统以 TIM2 **1 ms 中断**为心跳，各级周期函数按分频计数自动触发：

```
TIM2 1ms 中断 (心跳)
 │
 ├── 每 1ms ──── Timing_1ms()    → 蜂鸣器状态机
 ├── 每 2ms ──── Timing_2ms()    → LED 扫描
 ├── 每 5ms ──── Timing_5ms()    → ADC 轮询 (PA0/PA1/PA4)
 ├── 每 10ms ─── Timing_10ms()   → 传感器数据中值滤波
 ├── 每 50ms ─── Timing_50ms()   → 按键消抖扫描
 ├── 每 500ms ── Timing_500ms()  → 传感器读取 + 自动控制 + 报警检查
 └── 每 1s ───── Timing_1s()     → OLED 刷新 + 喂食控制 + WiFi 上报
```

| 周期 | 函数 | 职责 |
|------|------|------|
| 1 ms | Timing_1ms() | 蜂鸣器鸣叫时长控制 |
| 2 ms | Timing_2ms() | LED 闪烁节拍 |
| 5 ms | Timing_5ms() | 三路 ADC 轮询采集 |
| 10 ms | Timing_10ms() | 中值滤波，平滑传感器数据 |
| 50 ms | Timing_50ms() | 按键消抖（连续 3 次确认） |
| 500 ms | Timing_500ms() | 传感器读取、自动控制逻辑、报警检查 |
| 1 s | Timing_1s() | OLED 刷新、喂食倒计时、WiFi 数据上报 |

## 5 功能需求详细

### 5.1 温度采集与控制

#### 传感器交互示意

```
┌──────────┐    1-Wire     ┌──────────┐    TIM2     ┌──────────┐
│ DS18B20  │──────────────▶│ STM32    │───────────▶│ OLED 显示│
│ PB13     │   数据读取     │ PB13     │  500ms 调度 │ 水温页面 │
└──────────┘               └────┬─────┘             └──────────┘
                                │
                                │ 判断逻辑
                                ▼
                          ┌───────────┐
                          │ 温度 < 下限 │──YES──▶ relayHeat = ON
                          └───────────┘
                          ┌───────────┐
                          │ 温度 > 上限 │──YES──▶ relayHeat = OFF
                          └───────────┘
                          ┌───────────┐
                          │  其他区间  │──▶ 保持当前状态（滞环）
                          └───────────┘
```

#### 控制逻辑

| 项目 | 说明 |
|------|------|
| 传感器 | DS18B20, 1-Wire: PB13 |
| 采集周期 | 500 ms |
| 精度 | ±0.5 °C |
| 显示位置 | OLED 主页面 1，子页面 1-1 |
| 控制规则 | 水温 < tempLower → relayHeat = ON |
| | 水温 > tempUpper → relayHeat = OFF |
| | 中间区间 → 保持（滞环控制防抖动） |
| 异常处理 | 传感器断线 → 保持上一次有效值 |

### 5.2 水位监测与控制

#### 传感器交互示意

```
┌──────────────┐    模拟     ┌──────────┐    ADC     ┌──────────┐
│ 水位传感器   │───────────▶│ STM32    │──────────▶│ 水位 %   │
│ (浸入式)     │  0~3.3V    │ PA1      │  IN1      │ OLED 显示│
└──────────────┘            └────┬─────┘           └──────────┘
                                 │
                                 │ 判断逻辑
                                 ▼
                          ┌────────────────┐
                          │ 水位 > Max     │──▶ relayDrain = ON  (排水)
                          └────────────────┘    relayFill  = OFF
                          ┌────────────────┐
                          │ 水位 < Min     │──▶ relayFill  = ON  (加水)
                          └────────────────┘    relayDrain = OFF
                          ┌────────────────┐
                          │ Min ≤ 水位 ≤ Max│──▶ 两继电器均 OFF (安全区)
                          └────────────────┘
```

#### 控制逻辑

| 项目 | 说明 |
|------|------|
| 传感器 | 模拟水位传感器, ADC1_IN1: PA1 |
| 采集周期 | 500 ms |
| 数值范围 | 0~100% |

| | 安全区间 → 两继电器均 OFF |

### 5.6 按键处理

#### 按键扫描流程

```
┌──────────┐     ┌──────────┐     ┌──────────┐     ┌──────────┐
│ 读取 GPIO│────▶│ 连续3次  │────▶│ 消抖完成 │────▶│ 生成按键 │
│ KEY1~5   │     │ 确认稳定 │     │ = 有效   │     │ 事件     │
└──────────┘     └──────────┘     └──────────┘     └────┬─────┘
                                                        │
                                          ┌─────────────┼─────────────┐
                                          │             │             │
                                     短按事件       长按事件(2s)   长按释放
                                          │             │             │
                                          ▼             ▼             ▼
                                      页面切换     喂食/模式      参数+1
                                      阈值调整     切换           参数-1
```

#### 按键功能映射

| 按键 | 主页面 1（数据） | 主页面 2（阈值） | 主页面 3（手动） |
|------|------------------|------------------|------------------|
| KEY1 (PA8) | → 主页面 2 | → 主页面 3 | → 主页面 1 |
| KEY2 (PB3) | 子页面切换 | 子页面切换 | 手动模式切换继电器 |
| KEY3 (PB4) | 无功能 | 选中字段 +1 | 短按：切换自动↔手动 |
| KEY4 (PB8) | 无功能 | 选中字段 −1 | 手动模式切换 ON/OFF |
| KEY5 (PB1) | 无功能 | 切换上限/下限 | 长按 2s：触发喂食 |

#### 模式切换流程

```
                     KEY3 短按/长按
                          │
              ┌───────────┴───────────┐
              ▼                       ▼
        ┌──────────┐           ┌──────────┐
        │ 自动模式  │           │ 手动模式  │
        │ runMode=0│◀─────────▶│ runMode=1│
        └────┬─────┘           └────┬─────┘
             │                      │
             │   自动控制逻辑        │   KEY4 逐一切换
             │   温度/水位/空气      │   4 路继电器 ON/OFF
             ▼                      ▼
        relayHeat ──────────── 所有继电器
        relayFill             归零（切换瞬间）
        relayDrain
        relayOxygen
```

              ┌──────────────────┐

        │
        ▼

### 7.2 自动控制汇总

| 控制对象 | 传感器 | 执行器 | 控制规则 | 控制方式 |
|----------|--------|--------|----------|----------|
