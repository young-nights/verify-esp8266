## 2.1 传感器采集 (7 用例)

- [ ] **TC-SEN-001** DS18B20 温度读取
  - 操作：PB13 接入 DS18B20，上电运行，FinSH 执行 `sensor`
  - 现象：等待约 1.25s 后，`water_temp` 显示当前水温（如 25.3°C），连续观察 10 次，误差 ≤ ±0.5°C
  - 异常：若传感器未接，`water_temp` 保持 0.0 不更新

- [ ] **TC-SEN-002** DS18B20 断线容错
  - 操作：系统运行中拔掉 DS18B20 数据线，等 3s 后 FinSH 执行 `sensor`
  - 现象：`water_temp` 保持拔线前的最后一个有效值，不会变为 -999.0 或随机跳变
  - 恢复：重新接好传感器，1.25s 后温度恢复更新

- [ ] **TC-SEN-003** 空气质量 ADC 采集
  - 操作：PA4 接 MQ-135 AO 输出，上电运行 500ms，FinSH 执行 `sensor`
  - 现象：`air_quality` 显示 0~4095 范围内的数值，对着传感器吹气数值上升，静置后数值回落
  - 验证：万用表测 PA4 电压 V，期望 air_quality ≈ V/3.3 × 4095

- [ ] **TC-SEN-004** 水位 ADC 采集
  - 操作：PA1 接水位传感器 AO，上电运行，FinSH 执行 `sensor`
  - 现象：`water_level` 显示 0~100% 百分比，传感器浸入水中深度增加时数值上升
  - 换算：原始 ADC 值 × 100 / 4095

- [ ] **TC-SEN-005** PH 值 ADC 采集
  - 操作：PA0 接 PH 传感器 AO，上电运行，FinSH 执行 `sensor`
  - 现象：`ph_value` 显示 0.0~14.0 浮点值，放入中性溶液时接近 7.0
  - 换算：原始 ADC 值 × 14.0 / 4095

- [ ] **TC-SEN-006** 采集周期验证
  - 操作：示波器探头接 PB13（DS18B20 数据线），触发捕获 1-Wire 时序
  - 现象：每次转换包含 reset→write 0x44→等待 750ms→reset→read→500ms 延迟，总周期约 1.25s
  - 工具：示波器 10ms/div 时基

- [ ] **TC-SEN-007** 多通道 ADC 切换
  - 操作：PA0/PA1/PA4 分别接不同电位器（0V/1.65V/3.3V），等 1s 后 FinSH 执行 `sensor`
  - 现象：三个通道各自独立读取对应值，互不干扰。断开 PA0 后 PA1/PA4 数据不变
  - 验证：分别断开单个通道，其他两个数据稳定

## 2.2 自动控制 (10 用例)

- [ ] **TC-CTL-001** 低温自动加热
  - 操作：模式设为自动（`mode 0`），将 temp_lower 设为 30°C，当前水温 < 30°C
  - 现象：PB12 继电器吸合（LED 亮/可听到继电器"咔嗒"声），万用表测 PB12 为高电平（3.3V）
  - 前提：DS18B20 正常读取温度

- [ ] **TC-CTL-002** 高温停止加热
  - 操作：加热进行中，将传感器放入热水使水温 > temp_upper（默认 30°C）
  - 现象：PB12 继电器释放（LED 灭，万用表测 PB12 为低电平 0V），加热停止
  - 验证：水温回落到 temp_lower 以下后，PB12 重新吸合

- [ ] **TC-CTL-003** 水位高自动排水
  - 操作：水位传感器浸入较深，使 water_level > water_level_max（默认 80%）
  - 现象：PB15（排水继电器）吸合，PB14（加水继电器）释放
  - 验证：水位降低到 max 以下后，PB15 释放

- [ ] **TC-CTL-004** 水位低自动加水
  - 操作：水位传感器暴露在空气中，使 water_level < water_level_min（默认 40%）
  - 现象：PB14（加水继电器）吸合，PB15（排水继电器）释放
  - 验证：水位升到 min 以上后，PB14 释放

- [ ] **TC-CTL-005** 水位正常区间
  - 操作：水位在 min(40%) ~ max(80%) 之间
  - 现象：PB14 和 PB15 均释放（两个继电器都不动作）
  - 验证：万用表测 PB14=0V，PB15=0V

- [ ] **TC-CTL-006** 空气超标开增氧
  - 操作：对 MQ-135 喷气体使 air_quality > air_max（默认 500）
  - 现象：PA15（增氧继电器）吸合，可听到继电器动作声
  - 验证：万用表测 PA15 = 3.3V

- [ ] **TC-CTL-007** 空气恢复关增氧
  - 操作：移开气源，等 MQ-135 数值下降到 ≤ air_max
  - 现象：PA15 继电器释放，万用表测 PA15 = 0V
  - 验证：数值再次超标时 PA15 重新吸合

- [ ] **TC-CTL-008** 手动模式不自动控
  - 操作：KEY3 切换到手动模式，水温 < temp_lower
  - 现象：PB12 不吸合（自动加热不触发），所有继电器保持当前状态不动
  - 验证：等 5s，继电器无任何自动动作

- [ ] **TC-CTL-009** 模式切换：自动→手动
  - 操作：自动模式下按 KEY3，OLED 主页面 P1 显示"手动"
  - 现象：所有 4 个继电器立即关闭（可听到 4 声继电器释放声），用户需手动开启
  - 验证：万用表测 PB12/PB14/PB15/PA15 全部为 0V

- [ ] **TC-CTL-010** 控制响应时间
  - 操作：示波器通道 1 接 DS18B20 数据线，通道 2 接 PB12
  - 现象：温度读取完成到 PB12 动作的延迟 ≤ 500ms（一个控制线程周期）
  - 工具：示波器触发 DS18B20 读取结束边沿

## 2.3 声光报警 (8 用例)

- [ ] **TC-ALR-001** 温度越限报警
  - 操作：alarm_enable=1，使水温超出 temp_lower~temp_upper 范围
  - 现象：PB9 蜂鸣器以"响 0.5s → 停 2s → 响 0.5s → 停 2s"循环报警，OLED 上对应数据闪烁或正常显示
  - 验证：示波器测 PB9 波形为 0.5s 高 + 2s 低周期

- [ ] **TC-ALR-002** 水位异常报警
  - 操作：使 water_level < min 或 > max
  - 现象：蜂鸣器同样"响 0.5s / 停 2s"循环，与温度报警模式一致
  - 验证：水位恢复正常后蜂鸣器停止

- [ ] **TC-ALR-003** 空气超标报警
  - 操作：对 MQ-135 喷气使 air > air_max
  - 现象：蜂鸣器报警，同时增氧继电器 PA15 吸合（控制模块同时响应）
  - 验证：移开气源后 2s 内报警停止

- [ ] **TC-ALR-004** PH 越限报警
  - 操作：使 ph_value < ph_lower(6.5) 或 > ph_upper(8.5)
  - 现象：蜂鸣器报警，模式同上
  - 验证：PH 恢复到 6.5~8.5 后停止

- [ ] **TC-ALR-005** 报警自动解除
  - 操作：温度报警进行中，将水温恢复到正常范围
  - 现象：当前"响 0.5s"周期结束后，下一轮不再触发，蜂鸣器静默
  - 验证：持续观察 10s，蜂鸣器不再响

- [ ] **TC-ALR-006** 报警功能关闭
  - 操作：OLED 手动控制页将"报警"设为 OFF（alarm_enable=0），使温度超标
  - 现象：蜂鸣器完全不响，控制模块仍正常动作（加热/排水等）
  - 验证：将报警设回 ON，蜂鸣器立即开始报警

- [ ] **TC-ALR-007** 多参数同时越限
  - 操作：温度超标 + 水位超标 同时发生
  - 现象：蜂鸣器仍按"响 0.5s / 停 2s"统一模式报警，不会叠加变快或变响
  - 验证：恢复正常任一参数，报警不会立即停止（另一个参数仍超标）

- [ ] **TC-ALR-008** 邮箱事件传递
  - 操作：alarm_check() 检测到超标后调用 rt_mb_send
  - 现象：t_alarm 线程通过 rt_mb_recv 收到事件，触发蜂鸣器。若邮箱满（8 个事件积压），新事件丢弃
  - 验证：代码调试，确认 mb_alarm 有事件入队

## 2.4 喂食控制 (7 用例)

- [ ] **TC-FED-001** 自动定时喂食
  - 操作：feed_interval 设为 60s（快速测试），等待倒计时从 60 递减到 0
  - 现象：倒计时归零瞬间，舵机从闭合位置旋转到打开位置（约 90°），保持 3s 后自动回位，倒计时重置为 60
  - 验证：OLED 主页面 P2 喂食行从 `01:00` → `00:00` → 舵机动作 → `01:00`

- [ ] **TC-FED-002** 倒计时显示
  - 操作：OLED 切到主页面 P2
  - 现象：喂食行显示 `喂食    MM:SS` 格式，如 `喂食    03:45`，每秒递减 1
  - 验证：观察 5s，数字每秒减 1

- [ ] **TC-FED-003** 倒计时归零显示
  - 操作：倒计时归零时（舵机动作期间或刚重置），查看 OLED
  - 现象：短暂显示 `喂食    00:00`，舵机动作后重置为新值
  - 注意：若刚归零就立即触发喂食，`--:--` 可能不会显示（瞬间跳过）

- [ ] **TC-FED-004** 手动触发喂食
  - 操作：FinSH 执行 `feed` 命令（或在代码中调用 `app_feed_trigger()`）
  - 现象：舵机立即动作（不论当前倒计时多少），打开 3s 后关闭，倒计时重置为 feed_interval
  - 验证：倒计时还有 30min 时触发，舵机仍立即动作

- [ ] **TC-FED-005** 舵机 PWM 输出
  - 操作：示波器探头接 PA6（TIM3 CH1），触发喂食
  - 现象：PA6 输出 50Hz（周期 20ms）PWM 波。闭合时 CCR1=1500（脉宽 1.5ms），打开时 CCR1=2500（脉宽 2.5ms）
  - 工具：示波器 10ms/div，测量脉宽

- [ ] **TC-FED-006** 喂食状态标志
  - 操作：触发喂食，观察 `g_status.feeding` 变量
  - 现象：舵机打开 3s 期间 feeding=1，舵机关闭后 feeding=0
  - 验证：OLED 主页面 P2 喂食行在 feeding=1 期间可能显示不同状态

- [ ] **TC-FED-007** 喂食间隔可配置
  - 操作：FinSH 执行 `set_feed 7200`（2 小时），观察倒计时
  - 现象：倒计时从 7200 (=02:00:00) 开始递减，OLED 显示格式为 HH:MM
  - 验证：设为 120s 测试，OLED 显示 `02:00` 开始递减

## 2.5 OLED 显示 (15 用例)

- [x] **TC-DIS-001** 主页面 P1 实时数据显示
  - 操作：上电等待 1s，OLED 默认显示主页面
  - 现象：屏幕显示 4 行（16×16 汉字标签 + 数值）：
    - `温度    24.0C`（实际水温值）
    - `空气    320`（实际 ADC 值）
    - `水位    75%`（实际百分比）
    - `PH值    7.2`（实际 PH 值）
  - 底部右下角显示 `P1/2`

- [x] **TC-DIS-002** 主页面 P2 翻页
  - 操作：主页面 P1 状态下按 KEY2
  - 现象：OLED 清屏后显示 4 行新模式信息：
    - `模式    自动`（或 `手动`）
    - `喂食    02:30`（MM:SS 倒计时）
    - `WiFi    W-`（或 `W+`）
    - `热氧    ON OF`（加热/增氧继电器状态）
  - 底部显示 `P2/2`，再按 KEY2 返回 P1

- [x] **TC-DIS-003** 主页→阈值设置页
  - 操作：主页面（P1 或 P2）按 KEY1
  - 现象：OLED 清屏，显示阈值设置页 P1：
    - `阈值    Set`
    - `温下限  20.0C`
    - `温上限  30.0C`
    - `空气值  500`
  - 底部显示 `P1/2`

- [x] **TC-DIS-004** 阈值设置 P2 翻页
  - 操作：阈值页 P1 按 KEY2
  - 现象：显示阈值 P2：
    - `PH下限  6.5`
    - `PH上限  8.5`
    - `水位低  %40`
    - `水位高  %80`
  - 底部显示 `P2/2`

- [ ] **TC-DIS-005** 阈值设置→手动控制页
  - 操作：阈值页（P1 或 P2）按 KEY1
  - 现象：OLED 清屏，显示手动控制页 4 行（加热/加水/排水/增氧），每行显示设备名 + ON/OFF 状态
  - 底部显示 `P1/1`

- [ ] **TC-DIS-006** 手动控制→主页面循环
  - 操作：手动控制页按 KEY1
  - 现象：返回主页面 P1，完成三页循环（主页→阈值→手动→主页）

- [ ] **TC-DIS-007** 阈值编辑项光标
  - 操作：阈值页按 KEY5
  - 现象：当前选中项右侧出现 `<<` 标识（如 `温下限  20.0C<<`），再按 KEY5 光标移到下一项，7 项循环
  - 验证：跨子页时，光标在 P1 的 3 项（温下限/温上限/空气值）和 P2 的 4 项之间循环

- [ ] **TC-DIS-008** 阈值增加
  - 操作：阈值页，选中"温下限"（光标在该项），按 KEY3
  - 现象：温下限从 20.0 变为 21.0（步进 1.0°C），OLED 立即刷新显示新值
  - 同理：空气值步进 10，PH 步进 0.1，水位步进 5%

- [ ] **TC-DIS-009** 阈值减少
  - 操作：选中某阈值项，按 KEY4
  - 现象：对应值减少，最低减到 0 不再减（防下溢）
  - 验证：温下限 = 0.0 时再按 KEY4，值不变

- [ ] **TC-DIS-010** 手动控制设备光标
  - 操作：手动控制页按 KEY5
  - 现象：选中项右侧显示 `>K3` 提示（如 `增氧    ON>K3`），再按 KEY5 光标移到下一项（加热→加水→排水→增氧→报警→喂食，6 项循环）
  - 验证：只有 4 行显示，选中项若超出当前屏幕会自动滚入

- [ ] **TC-DIS-011** 手动控制开关切换
  - 操作：手动控制页，选中"加热"（当前 OFF），按 KEY3
  - 现象：状态从 OFF 变为 ON，同时 PB12 继电器吸合（可听到"咔嗒"声）。再按 KEY3 变回 OFF，继电器释放
  - 验证：万用表测 PB12 电平随按键同步变化

- [ ] **TC-DIS-012** 汉字显示正确性
  - 操作：观察主页面 P1 每行左侧汉字标签
  - 现象：`温度` `空气` `水位` `PH值` 四个标签汉字笔画清晰，无乱码、缺笔、错位
  - 验证：与字库中原始点阵数据一致（已通过 Python 脚本验证）

- [ ] **TC-DIS-013** 数据自动刷新
  - 操作：保持在主页面 P1，不按任何键，等待 3s
  - 现象：OLED 上的传感器数值每秒自动更新（t_display 线程 1s 周期），水温小数位可能变化
  - 验证：用手捂热 DS18B20，数值 2~3s 内上升

- [ ] **TC-DIS-014** 页面指示器
  - 操作：切换不同页面和子页
  - 现象：所有页面右下角均显示当前页码 `P1/2` `P2/2` 或 `P1/1`，不被内容覆盖
  - 验证：即使数据较长，指示器位置不变（固定在 x=90, page 6）

- [ ] **TC-DIS-015** 混合字体布局
  - 操作：观察主页面 P1 每行
  - 现象：每行左侧为 16px 高汉字（占 2 个 OLED page），右侧为 6×12 ASCII 数值。汉字与数字之间有 2px 间距，整体视觉协调
  - 验证：128 像素宽度内，汉字最多放 3 个（48px），剩余空间给 ASCII

## 2.6 按键扫描 (8 用例)

- [x] **TC-KEY-001** KEY1 页面切换
  - 操作：按下 KEY1（PA8，低电平有效），持续 150ms 后松开
  - 现象：OLED 页面从主页切换到阈值设置页（或从阈值到手动，或从手动到主页），无延迟感
  - 验证：`g_key_event` 值变为 1

- [x] **TC-KEY-002** KEY2 子页翻页
  - 操作：按下 KEY2（PB3）
  - 现象：当前页面的子页从 P1 切到 P2（或 P2→P1），内容完全替换
  - 验证：主页 P1 显示传感器数据，按 KEY2 后变为 P2 显示模式/喂食信息

- [x] **TC-KEY-003** KEY3 功能触发
  - 操作：按下 KEY3（PB4）
  - 现象：在阈值页触发阈值 +1，在手动页触发开关切换，在主页无动作
  - 验证：`g_key_event` 值变为 3

- [x] **TC-KEY-004** KEY4 阈值减
  - 操作：阈值页按 KEY4（PB8）
  - 现象：当前选中阈值项减少，OLED 立即更新
  - 验证：`g_key_event` 值变为 4

- [x] **TC-KEY-005** KEY5 编辑项切换
  - 操作：阈值/手动页按 KEY5（PB1）
  - 现象：`<<` 或 `>K3` 光标移向下一项
  - 验证：`g_key_event` 值变为 5

- [x] **TC-KEY-006** 防抖验证
  - 操作：快速轻按一次 KEY1（按下 < 100ms 松开）
  - 现象：若按下时间不足 150ms（3 次 × 50ms 采样），不触发事件，页面不变
  - 验证：按住 ≥ 150ms 后松开，页面切换一次且仅一次

- [x] **TC-KEY-007** 长按不重复
  - 操作：按住 KEY1 不放，持续 5s
  - 现象：页面只切换一次，不会因为长按而快速翻页。松开后再按才会再次触发
  - 验证：当前代码无长按重复逻辑，debounce 清零依赖 key 变化

- [x] **TC-KEY-008** 多按键优先级
  - 操作：同时按下 KEY1 和 KEY3
  - 现象：key_scan 函数按 KEY1→KEY5 顺序扫描，KEY1 优先返回。即页面切换，不触发 KEY3 功能
  - 验证：松开后只发生一次页面切换，无阈值变化

## 2.7 WiFi 通信 (7 用例)

- [ ] **TC-WIF-001** USART2 串口初始化
  - 操作：上电，示波器测 PA2（TX）空闲电平
  - 现象：PA2 空闲为高电平（3.3V），PA3（RX）为上拉输入
  - 验证：115200 波特率，8N1 格式。发送 'A'（0x41）时 PA2 波形符合 UART 协议

- [ ] **TC-WIF-002** ESP-01S AT 指令序列
  - 操作：上电自动执行，逻辑分析仪接 PA2（MCU→ESP）和 PA3（ESP→MCU）

  - 验证：手动计算 SUM = (0x01+0x0A+payload之和) & 0xFF，与帧中 SUM 字节一致

- [ ] **TC-WIF-005** 帧校验和验证

  - 现象：SUM = (CMD + LEN + DATA[0] + DATA[1] + ... + DATA[N-1]) & 0xFF
