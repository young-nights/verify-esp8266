# 智能鱼缸系统 — OLED 显示规划

> 版本：V3.1 | 日期：2026-05-04
> 屏幕：SSD1306 0.96" 128×64 I²C (PA11/PA12)
> 字体：6×12 点阵（宋体，列行式 逆向 阴码）
> 可用行：row2 / row4 / row6（每行 12px 高，共 3 行内容区）
> 每行最大容量：约 21 个 ASCII 或 10 个汉字
> 页面指示器：row0 右上角显示当前主/子页面编号（如 1/1）
> MCU：STM32F103C8T6 (LQFP-48, 72MHz, 3.3V)

---

## 一、屏幕区域划分

```
  ← 0                    128 →
  ┌──────────────────────────┐ ↑

  ├──────────────────────────┤
  │ Row1~2  内容区 ①         │  12px
```

**页面指示器**：row0 右侧显示 `主页/子页`（如 `1/1`），列位置 col 102~120。

### 按键导航速查

| 按键 | 引脚 | 输入模式 | 功能说明 |
|------|------|----------|----------|
| **KEY1** | PA8 | 下拉输入 | 切换主页面：1→2→3→1（循环），进入新主页面时子页面归零 |
| **KEY2** | PB3 | 下拉输入 | 切换子页面：在当前主页面内循环切换（子页 1→2→3→...→1） |
| **KEY3** | PB4 | 下拉输入 | 阈值页：选中项数值+1；手动页短按：切换自动/手动模式；**长按 2s：切换自动/手动模式** |
| **KEY4** | PB8 | 下拉输入 | 阈值页：选中项数值-1；手动页：切换继电器 ON/OFF |
| **KEY5** | PB1 | 下拉输入 | 阈值页（温度/水位/PH）：切换选中下限/上限；**长按 2s 触发喂食** |

> 注：所有按键均为高电平触发，内部下拉输入，外部上拉至 3.3V

## 五、主页面 2 — 阈值设置

展示和调节各传感器的报警阈值。**操作模式为"选中-调节"**：

1. KEY2 切换子页面（不同参数类别）
2. KEY5 **短按**切换当前选中字段（下限 ↔ 上限）
3. KEY3（短按）选中值+  /  KEY4（短按）选中值-

### 子页面 2-1：温度阈值

```
  ┌──────────────────────────────┐
  │                    2/1       │ Row0
  │                              │ Row1
  │ 温度:20.0~30.0               │ Row2（当前范围概览）
  │                              │ Row3
  │ >下限:20.0                   │ Row4（> 表示当前选中）
  │                              │ Row5
  │  上限:30.0℃   K5:Sw         │ Row6
  └──────────────────────────────┘
```

**选中切换过程**：

```
  初始状态（选中下限）          按 KEY5（选中上限）
  ┌──────────────────┐         ┌──────────────────┐
  │ >下限:20.0        │  KEY5   │  下限:20.0        │
  │  上限:30.0℃      │ ─────→  │ >上限:30.0℃      │
  └──────────────────┘         └──────────────────┘
  ↑ > 在 row4 左侧              ↑ > 在 row6 左侧
```

**数值调节过程**（以选中下限为例）：

```
  按 KEY3                          按 KEY4
  ┌──────────────────┐            ┌──────────────────┐
  │ >下限:21.0        │            │ >下限:19.0        │
  │  上限:30.0℃      │            │  上限:30.0℃      │
  └──────────────────┘            └──────────────────┘
       +1℃                             -1℃
```

**操作步骤**：

| 步骤 | 按键 | 效果 |
|------|------|------|
| 1 | KEY5（短按） | 切换选中：下限 ↔ 上限（`>` 标记随之移动） |
| 2 | KEY3（短按） | 选中项 +1°C |
| 2 | KEY4（短按） | 选中项 -1°C |

- Row6 右侧固定显示 `K5:Sw` 提示 KEY5 切换字段功能

### 自动/手动模式切换

```
  按 KEY3（短按或长按 2s）

  自动模式                     手动模式
  ┌──────────────────┐        ┌──────────────────┐
  │ 自动模式!         │        │ >加热:ON          │
  │ K3:手动           │  ───→  │ K3:模式  K4:+/-   │
  └──────────────────┘        └──────────────────┘
  继电器由系统控制              KEY4 可手动开关继电器
  → 切换到手动时所有继电器归零  │
```

- KEY3 短按或长按 2s 均可切换模式
- 从自动切到手动时，所有继电器自动归零（OFF）
- 自动模式下 KEY4 无效
- 切换时 row4、row6 区域清空重绘

```
          │    │  子3-1→子3-2→子3-3→子3-4→子3-1│    │
          │    └───────────────────────────────┘    │

          └─────────────────────────────────────────┘
                    KEY1 从主3回到主1
```
